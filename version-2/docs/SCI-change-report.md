## 計算與估計

SCI =（1 − 導入後人工投入時間 ÷ 全人工投入時間）× 100。

- 職業 modeledWorkShare：對核心與適用延伸工作範圍的涵蓋率模型估計；不能當成 AI 協作比例。每個職業已重新配置，未以它再次乘上工時或放大結果。
- 任務 estimatedAiAssistShare：各階段工時占比 × AI 可協作份額加總；不能當成節省工時。
- estimatedRetainedHumanShare：各階段工時占比 ×〔(1 − 可協作份額) + 可協作份額 × 覆核負擔 + 可協作份額 × 例外率 × 例外處置負擔〕。
- 所有步驟占比加總為 1；人工涵蓋未交由 AI 的專業工作、實體操作、決策、覆核及例外處理。
- 職業 workflowWeights 設為 null，weightBasis 設為 actual-user-entered-baseline-minutes。不使用預設四項的 .38/.29/.20/.13 權重。
- 新增「同一工作量全人工時間」及「導入後含覆核與例外的人工時間」輸入。兩者可提供觀察值；未填時以模型估計。主要手動且未填全人工時，使用其目前人工時間作分母；已用 AI 且未填全人工時，用任務參考估計並保留來源標記。
- 工作量選項是一次任務的量或複雜度，已移除「占整體工時多少」的錯誤語意。頻率與分鐘不能再重複乘涵蓋率。
- 廣泛舊流程與細分新流程有 conflictsWith 防重複檢查；其他任務以各自 boundary 指定工時分界。跨同場會議、同一份成果仍須依邊界分配，系統無法只從總分鐘判定使用者是否重填同一工作。

### 已知工時案例

| 項目 | 值 |
| --- | ---: |
| 同一工作量全人工 | 600 分鐘（10 小時） |
| 導入後人工（含覆核、例外、操作與決策） | 240 分鐘（4 小時） |
| 頻率 | 每月 1 次 |
| SCI | (1 − 240 / 600) × 100 = 60 |

可於專案經理任務填寫目前手動時間 600、全人工時間 600、導入後人工時間 240，結果應為 SCI 60。這是確定工時的公式示例，不代表模型承諾每個專案都節省 60%。

### 一般開發專案經理

#### P01 需求整理與範圍管理

- 工作範圍：本次工作：彙整需求與版本、變更申請；檢查軟體、硬體或並行開發；按實際交付範疇選擇證據；完成：整理需求基線、验收条件與变更影响表並附來源與版本。

## 引用、權重與遷移規則

- 所有既有任務 ID 均保留。廣泛工作不直接改成狹窄任務；專職拆解新增獨立 ID，舊任務 retained 但在不合理配對中撤除。
- 核心與延伸對照逐職業定義，沒有依關鍵字、tags 或現有流程數量生成職業配對。
- 階段權重存於該任務的 stageWorkShare，並檢查加總；職業層沒有固定權重陣列或長度四驗證。
- 欄位、卡片、詳細流程、分身名稱、referenceScales、workUnit、metrics 均用 task ID。修改共用任務會同步影響所有引用者，原任務完整保留以便追溯。
- 附件 app.js 原本只有匿名訪客 ID 存於 localStorage，沒有找到本機儲存的測驗草稿恢復程式；没有猜測其他未提供模組的儲存鍵。
- 新 snapshot/result 附 schemaVersion=3.0、roleId。calculateAssessment 拒絕舊 schema、未知職業、職業外任務、重複 ID 與互斥重疊任務。
- 提供 SCIWorkflowV2.migrate(saved) 與 globalThis.restoreSciAssessment(saved)。舊 schema 必須重新選擇，保留 previousAssessment 供對照；拆分職業只列候選，不會選第一項。已有外部草稿恢復程式時，應以 restoreSciAssessment 接入，禁止直接 Object.assign 舊資料。
- 切換職業會清除前職業勾選與時間設定；避免篩選畫面變了而結果仍包含舊任務。

## 你可以自行驗收的項目

1. 兩個工作領域應分別顯示「軟硬體專案開發」「產品開發」。
2. 切換職業後，舊勾選與工時應清空，核心與延伸任務依職責顯示。
3. 專案經理有四項核心，採購為延伸；軟體、硬體詳細流程內容不同。
4. 產品經理、產品企劃、軟體、韌體、硬體、機構、工業設計、測試、NPI 的任務互相區別。
5. 查看任務卡片說明與展開流程，同 ID 的輸入、產出與人工責任一致。
6. 各職業任務數應依內容不同，不再強制四項；程式已移除六項勾選上限，也不為驗收湊出七項任務。
7. 已知 600→240 分鐘案例 SCI 為 60；涵蓋率不應影響此值。
8. 舊 schema 及拆分職業資料顯示重新選擇；不能自動選中產品經理或其中一種工程師。
